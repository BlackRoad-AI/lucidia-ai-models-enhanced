## 🎮 The 3D Experience

Open `index.html` in your browser. You'll see the full product portal immediately — click any card to open a tool, or hit **"Explore in 3D"** to walk through a Minnesota wilderness landscape where all 11 AI models appear as glowing spheres. Walk near one to see its portal card, then click **"Open Portal"** to launch it.

**Controls in 3D world:**
| Key | Action |
|-----|--------|
| `W A S D` | Move |
| `Mouse` | Look around |
| `Shift` | Sprint |
| `Space` | Jump |
| `ESC` | Exit 3D / release cursor |
| **◎ Back to Hub** button | Return to product portal |

## 🧑‍💻 Developer Info

This repo also ships a Python pipeline library (`src/ai_models_enhanced.py`) for model quantization, LoRA adapter management, and fine-tuning job tracking — all backed by SQLite, no GPU required.

```bash
# Quick start (Python API)
git clone https://github.com/BlackRoad-AI/lucidia-ai-models-enhanced.git
cd lucidia-ai-models-enhanced
pip install pytest
pytest tests/ -v   # 36 tests, all pass
```

Full API reference and database schema are in [`CONTRIBUTING.md`](CONTRIBUTING.md).
